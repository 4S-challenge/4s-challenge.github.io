개인정보처리방침

시행일: 2026년 10월 27일 (이전: 2026년 10월 21일, 웹 주소를 4s-challenge.ohsangplay.com으로 변경)

한눈에 보기
  • 회원가입·로그인이 없고, 이름·이메일·전화번호·위치·연락처를 받지 않습니다.
  • 랭킹에 직접 입력한 영문 이니셜 3글자와 게임 기록만 저장하고, 랭킹은 누구나 볼 수 있습니다.
  • Android·iOS 앱에는 화면 아래에 Google AdMob 배너 광고가 나옵니다. 광고를 위해 Google이 광고 ID 등 기기 정보를 처리합니다(4번). 웹에는 광고가 없습니다.
  • 결제와 분석 도구는 없습니다.

4S 챌린지 - 숫자야구(이하 “서비스”, 웹과 Android·iOS 앱 포함)는 이용자의 개인정보를 최소한으로만 처리하며, 「개인정보 보호법」 등 관련 법령을 지킵니다.

1.처리하는 정보와 목적

기능처리하는 정보목적보관 기간
혼자 하기 임의로 만든 게임 번호, 비밀 숫자, 시도 횟수, 시작·정답 시각 서버에서 판정해 결과 조작 방지 시작 후 2일 뒤 자동 삭제
랭킹 등록 (선택) 이용자가 입력한 영문 이니셜 3글자, 시도 횟수, 걸린 시간, 등록 시각 랭킹 표시 삭제 요청 시 또는 서비스 종료 시까지
친구와 대결 입력한 이니셜 3글자, 방 코드, 임의로 만든 참가자 번호, 각자 정한 비밀 숫자, 던진 숫자 대결 진행, 연결이 끊겼을 때 이어하기 마지막 활동 후 방에 아무도 없이 15분, 또는 마지막 활동 후 2시간이 지나면 자동 삭제

이니셜은 이용자가 직접 고르는 3글자이며, 실명을 넣을 필요가 없습니다. 이니셜만으로 특정 개인을 알아볼 수 없도록 실명 대신 별명 머리글자 사용을 권장합니다.

2.자동으로 처리되는 정보

서비스에 접속하면 인터넷 통신 과정에서 IP 주소, 접속 시각, 브라우저·기기 종류 같은 정보가 아래 업체의 서버를 거칩니다. 서비스 운영자는 이 정보를 따로 저장하거나 분석하지 않습니다.

  • Cloudflare, Inc.: 게임 서버(판정, 랭킹, 대결방) 운영
  • GitHub, Inc.: 웹 페이지 호스팅 (4s-challenge.ohsangplay.com)
  • Google LLC: 화면 글꼴(Google Fonts) 제공

웹에서는 쿠키나 광고 식별자를 사용하지 않습니다. 앱의 광고는 4번을 참고해 주세요. 결과 공유·복사는 기기 안에서만 동작합니다.

3.처리 위탁과 국외 이전

서비스 운영을 위해 아래와 같이 정보 처리를 맡깁니다. 이 업체들의 서버는 대한민국 밖(미국 등 각 업체의 세계 각지 데이터센터)에 있을 수 있으며, 서비스를 이용할 때 인터넷을 통해 전송됩니다.

받는 곳맡기는 일전송되는 정보보관 기간
Cloudflare, Inc. (미국)
개인정보처리방침		 게임 서버, 데이터 저장 1번 표의 정보, 접속 IP 1번 표의 기간. 접속 기록은 Cloudflare 정책에 따름
GitHub, Inc. (미국)
개인정보처리방침		 웹 페이지 호스팅 접속 IP, 접속 기록 GitHub 정책에 따름
Google LLC (미국)
개인정보처리방침		 글꼴 파일 제공, 앱 광고(AdMob) 접속 IP, 접속 기록. 앱은 4번의 광고 관련 정보 Google 정책에 따름

위 경우 외에는 이용자의 정보를 다른 곳에 제공하거나 판매하지 않습니다.

4.앱 광고 (Google AdMob)

Android·iOS 앱의 홈, 결과, 랭킹, 대결 대기·결과 화면 맨 아래에 Google AdMob 배너 광고가 나옵니다. 게임 중(숫자를 입력하는 화면)에는 광고를 띄우지 않습니다.

  • 처리하는 정보: 광고 ID(Android 광고 ID, iOS IDFA), IP 주소, 기기 종류·운영체제, 광고를 보거나 누른 기록 등
  • 처리하는 곳: Google LLC. 서비스 운영자는 이 정보를 받거나 저장하지 않습니다.
  • 목적: 광고 표시, 광고 성과 측정, 부정 클릭 방지, (허용한 경우) 맞춤형 광고
  • 설정: Android는 설정 › Google › 광고에서 광고 ID를 삭제하거나 재설정할 수 있고, iOS는 설정 › 개인정보 보호 및 보안 › 추적에서 추적을 허용하지 않을 수 있습니다. 거부해도 맞춤형이 아닌 광고가 나올 수 있습니다.
  • 자세한 내용: Google이 파트너 앱의 정보를 사용하는 방식, Google 개인정보처리방침

5.파기

보관 기간이 끝난 정보는 서버에서 자동으로 지웁니다. 지운 정보는 되살릴 수 없습니다.

6.이용자의 권리

랭킹에 올린 기록을 보거나 지우고 싶으면 아래 문의처로 알려 주세요. 이니셜, 순위, 등록한 날짜를 함께 적어 주시면 확인 후 지체 없이 지웁니다. 로그인이 없어 본인 확인이 어려우므로, 요청된 기록이 맞는지 등록 시각과 기록으로 확인합니다.

7.아동의 개인정보

서비스는 나이와 관계없이 이용할 수 있으며, 아동을 포함한 누구에게도 이름·연락처 같은 개인정보를 요구하지 않습니다.

8.안전성 확보 조치

  • 모든 통신은 암호화(HTTPS, WSS)됩니다.
  • 서버 관리 권한은 운영자에게만 있습니다.
  • 필요한 정보만, 필요한 기간 동안만 보관합니다.
